# React State Management Hooks

## Overview

This app demonstrates React state management using hooks like useContext, useReducer, createContext, useMemo, and more. It was built in September 2021 and also integrates Ant Design (antd), node-sass, Less, and customize-cra.

## Getting started

### Requirements

- Yarn or npm

### Setup

1. Clone the repository.
2. Install dependencies:

   ```sh
   yarn install
   ```

3. Request the .env file from authorized personnel.

## Running the Application

### Development Mode

To start the development server:

```sh
yarn dev
```

After running, access the application at:

```sh
http://localhost:3000/
```

### Production Mode

To build and start the production server:

```sh
yarn build
yarn start
```
